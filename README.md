# UniLoad

Планировщик учебных заданий. Студент добавляет работу, указывает дисциплину и срок, затем отмечает выполнение. Список хранится в браузере.

## Запуск

Откройте `tempPage/index.html` в браузере. Сейчас это статическая главная страница: ссылки работают, задания приведены для примера, форма и кнопки управления отключены.

## Структура проекта

```text
tempPage/        HTML-страница и базовые стили
src/
  components/   кнопки, поля формы, карточки
  pages/        главная страница, список и форма
  domain/       модель задания и расчёт срочности
  storage/      работа с localStorage
  styles/       стили приложения
public/         статические файлы
docs/           план разработки
```

Для приложения выбран React, Vite и JavaScript. Настройка сборки запланирована в [FE-003](https://github.com/SkyBlinkkk/uniload/issues/3). Пока зависимости для просмотра страницы не нужны.

## План разработки

[Backlog по неделям](docs/backlog.md) · [Задачи в GitHub Issues](https://github.com/SkyBlinkkk/uniload/issues?q=is%3Aissue) · [Открытые задачи](https://github.com/SkyBlinkkk/uniload/issues?q=is%3Aopen+label%3ABACKLOG)

В первую версию входят создание, редактирование и удаление заданий, фильтры, сортировка по сроку, отметка выполнения и счётчики. Предусмотрены пустой список и сообщения об ошибках сохранения.

Регистрация, сервер, календарь и уведомления в этот объём не входят. Данные доступны только в том браузере и на том адресе, где были сохранены. После очистки данных браузера список удаляется.
