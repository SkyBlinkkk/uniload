# UniLoad

Учебный планировщик заданий и дедлайнов для студента. Основа проекта — ТЗ из ЛР №2 и пользовательский путь из ЛР №3.

## Текущий этап

ЛР №4: подготовлены структура репозитория, backlog frontend-разработки и семантическая главная страница. Реализация React-приложения начинается с FE-003. В этой версии нет бизнес-логики, сохранения и законченного дизайна.

## Как посмотреть страницу

Откройте `tempPage/index.html` в браузере. Установка Node.js для статической страницы не требуется. Навигационные ссылки переходят к областям страницы. Примеры заданий и счётчики статические; поля и кнопки управления отключены до реализации.

## Планируемый стек

React, Vite, JavaScript, CSS; localStorage; Git. Версии зависимостей и команды `dev`, `build`, `preview` будут зафиксированы в FE-003. В этом этапе package.json и сторонние зависимости не нужны.

## Структура

```text
src/
  components/  общие элементы интерфейса
  pages/       главная, список, форма
  domain/      модель задачи и срочность
  storage/     чтение и запись localStorage
  styles/      стили приложения
public/        статические ресурсы
tempPage/      начальная HTML-страница
docs/          backlog и порядок дальнейшей работы
```

## Состав MVP

Создание, редактирование и подтверждаемое удаление задания; название, дисциплина, календарный срок; срочность; совместные фильтры; сортировка; выполнение и общие счётчики; восстановление локального списка; пустые и ошибочные состояния.

Регистрация, сервер, синхронизация, уведомления и календарь в MVP не входят. Задачи будут храниться только в текущем браузере на одном адресе. Очистка данных браузера удаляет список.

## Backlog и Git

24 задачи на восемь недель в `docs/backlog.md`. Оценки — рабочие часы одного разработчика, не календарные дедлайны. Коммит связывается с задачей, например `feat(FE-002): create semantic home page structure`. Локальные подготовительные коммиты не означают завершения размещения на GitHub.
