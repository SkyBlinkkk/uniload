# UniLoad

Планировщик учебных заданий. Можно добавить работу, указать дисциплину и срок, отредактировать её и отметить выполнение. Список сохраняется в браузере.

## Запуск

Нужны Node.js 22.12 или новее и pnpm 11.25.0. Если pnpm ещё не установлен: `npm install -g pnpm@11.25.0`.

Из папки проекта:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес, который покажет Vite. Для сборки и её локального просмотра:

```sh
pnpm build
pnpm preview
```

Готовые файлы появятся в `dist`. Приложение нужно открывать через HTTP-сервер, а не двойным щелчком по `index.html`. Статическая страница ЛР № 4–5 сохранена в `tempPage`; она запускается отдельно и не управляет заданиями.

## Что работает

На главной странице показаны ближайшие активные задания и общая сводка. В списке можно создавать и редактировать задания, удалять их после подтверждения и переключать выполнение в обе стороны. Фильтры дисциплины и выполнения применяются совместно; сортировка меняет порядок сроков. Общие счётчики от фильтров не зависят.

Срочность определяется по календарной дате устройства: прошедший срок, сегодня, ближайшие два дня или обычный срок. Выполненные задания не считаются просроченными. При первом запуске список пуст; примеры автоматически не добавляются.

У формы есть проверка обязательных полей и календарной даты. Отмена не меняет данные. При отказе сохранения изменения остаются на экране, появляется предупреждение и кнопка повтора. Повреждённая запись не затирается автоматически: её замена требует подтверждения.

## Структура

```text
src/
  App.jsx        состояние списка и обработчики действий
  components/    форма, карточка, фильтры, сводка, диалог
  pages/         главная и список
  domain/        модель, проверка полей, срочность и отбор
  hooks/         переходы между экранами и текущая дата
  storage/       чтение и запись localStorage
  styles/        стили приложения
public/          иконка вкладки
tempPage/        страница предыдущих лабораторных работ
docs/            backlog и объём MVP
```

React отвечает за интерфейс, Vite — за запуск и сборку. Сторонних библиотек компонентов и сервера нет. Переходы используют адреса `#home`, `#tasks`, `#new` и `#edit/идентификатор`.

## Автоматические тесты

После установки зависимостей из корня проекта:

```sh
pnpm test:run
```

Команда выполняет все проверки один раз и возвращает ненулевой код при ошибке. `pnpm test` запускает режим наблюдения; `pnpm test:run --reporter=verbose` показывает каждый сценарий. Отдельно проверить форму можно командой `pnpm test:run src/components/TaskForm.test.jsx`.

Добавлены 12 тестов для трёх требований ТЗ: FR-02 — валидация, FR-08 — совместные фильтры, FR-10 — выполнение и общие счётчики. Используются Vitest, React Testing Library, user-event и jsdom. Тесты находятся рядом с компонентами и функциями; общая подготовка — в `src/test/setup.js`, конфигурация — в `vitest.config.js`. Каждый тест получает отдельные исходные данные; содержимое вашего браузера не используется.

Условия и ожидаемые результаты перечислены в [плане тестирования](docs/testing.md). Проверки в jsdom не оценивают внешний вид страницы и совместимость реальных браузеров. Повторное монтирование App проверяет чтение сохранённого состояния, но не заменяет E2E-проверку перезагрузки вкладки.

## Проверка и ограничения

Проверены сборка и основной сценарий в Microsoft Edge 155.0.4283.62: создание → изменение → выполнение → повторное открытие → удаление. Дополнительно проверены фильтры, отмены, ошибки хранения, длинный текст, увеличение шрифта до 200% и ширины 320, 360, 768, 1200 и 1440 px. Подписи полей и действия доступны с клавиатуры.

Данные находятся в `localStorage` под ключом `uniload.tasks.v1`. Они доступны только для того же адреса, протокола и порта. Поэтому dev-сервер, preview и другой домен имеют разные списки. Очистка данных браузера удаляет задания. При предупреждении о несохранённых изменениях не закрывайте вкладку до успешного повтора.

Учётные записи, сервер, перенос между устройствами и согласование одновременных изменений в нескольких вкладках не реализованы. В ЛР № 7 добавлены автоматические проверки трёх требований; результаты приведены в плане тестирования. Проверка Chrome, Firefox и Safari остаётся открытой.
