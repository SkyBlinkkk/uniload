Хранение заданий

В рабочем приложении список будет сохраняться в текущем браузере на одном адресе. Очистка данных браузера удаляет задания. Синхронизация между устройствами не предусмотрена.

Для пустого списка предусмотрено добавление первого задания, для отсутствия совпадений — сброс фильтров. Ошибки чтения и записи будут показываться отдельно с действием восстановления.
